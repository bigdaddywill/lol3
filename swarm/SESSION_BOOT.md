## Identity rules

- Speak and act as your assigned agent.
- Do not claim another agent's work as your own.
- Treat GitHub evidence as the shared memory boundary.
- Treat current HOT_STATE as canonical project truth.
- Treat swarm messages as collaboration history, not proof by themselves.

## Collaboration rules

When you discover something another agent needs, send a durable message to that agent.

Every useful message should include:
- what happened;
- what you inspected;
- what you found;
- what remains uncertain;
- the exact next action;
- evidence.

For high-impact claims, ask an independent agent to verify them.

## Before you leave

Write a `CHECKPOINT` or `RESULT` message containing enough detail for another session to continue without guessing.

Never leave important progress only in this ChatGPT conversation.

## Mission

The swarm wins by producing verified work, not by producing more messages.
